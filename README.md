# bubbleGame

🇫🇷 **Français** · [🇬🇧 English below](#english)

Exercice simple d'un jeu de tir sur bulles, en JavaScript natif : des bulles apparaissent à l'écran et il faut les éclater pour marquer des points.

## Fonctionnement

- Une nouvelle bulle apparaît toutes les 300 ms
- Chaque bulle disparaît d'elle-même au bout de 8 s
- Un compteur affiche le nombre de bulles éclatées

## Fichiers

`index.html` · `index.js` (logique du jeu) · `style.css`

## Jouer

Aucune dépendance : ouvrir `index.html` dans un navigateur.

## 🇬🇧 English

A simple bubble-popping shooter exercise in vanilla JavaScript: bubbles appear on screen and you pop them to score.

**How it works:** a new bubble every 300 ms, each one disappears after 8 s, a counter shows how many you popped.

**Files:** `index.html`, `index.js` (game logic), `style.css`. **Play:** open `index.html` in a browser — no dependencies.
